# VK DeepSeek Bot

## Пошаговая инструкция

---

### Шаг 1. Создать сообщество ВК

1. Зайди на https://vk.com/groups → **«Создать сообщество»**
2. Выбери любой тип (например, «Группа»)
3. Задай название

---

### Шаг 2. Получить токен ВК

1. Зайди в **Управление** сообществом
2. Раздел **Работа с API** → **Создать ключ**
3. Выбери права: **messages** (обязательно), **photos** (для отправки фото)
4. Скопируй токен — начинается на `vk1.a.`

---

### Шаг 3. Настроить Callback API

1. В **Работа с API** → **Callback API**
2. Версия API: **5.199**
3. Включи событие **«Входящее сообщение»**
4. Скопируй **код подтверждения** (строка из цифр и букв) — он понадобится позже
5. Поле **«Адрес»** пока оставь пустым — заполним после запуска ngrok

---

### Шаг 4. Запустить локально + ngrok

```bash
cd ~/vk-deepseek-bot

# 1. Задать переменные
export DEEPSEEK_API_KEY="sk-твой_ключ"
export VK_TOKEN="vk1.a.твой_токен"
export CONFIRMATION_CODE="код_подтверждения"

# 2. Запустить бота
python3 bot.py
```

**В другом терминале:**
```bash
# Установить ngrok (если нет)
brew install ngrok

# Запустить туннель
ngrok http 5000
```

Скопируй URL вида `https://xxxx-xx-xx-xx-xx.ngrok-free.app` и вставь в поле **«Адрес»** в Callback API ВК, добавив `/callback`:

```
https://xxxx-xx-xx-xx-xx.ngrok-free.app/callback
```

Нажми **«Подтвердить»** в ВК.

---

### Шаг 5. Проверить

Напиши любое сообщение в сообщество → бот ответит через DeepSeek.
