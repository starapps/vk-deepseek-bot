# VK DeepSeek Bot

> Чат-бот для сообществ ВКонтакте на базе **DeepSeek**. Ведёт диалог с пользователем, помнит контекст (до 20 последних сообщений) и отвечает от лица краткого и по-делу ассистента. Работает через **Long Poll API** — без публичного адреса, вебхуков и ngrok.

## Возможности

- 🧠 **Память диалога** — до 20 последних сообщений на пользователя; контекст хранится в памяти процесса в рамках сессии.
- ⚡ **DeepSeek** (`deepseek-chat`) — генерация ответов через OpenAI-совместимый API.
- ⌨️ **Индикатор «печатает…»** — бот показывает статус набора, пока идёт запрос к модели.
- 🔁 **Long Poll API** — сообщения принимаются лонгполлом (`wait=25`); публичный URL не нужен, бот запускается локально.
- 🛡️ **Устойчивость** — переподключение при `failed` в Long Poll, таймауты, ретраи с паузой при сбоях сети.
- 🎛️ **Параметры генерации** — `temperature=0.7`, `max_tokens=2000`, системный промпт задаёт краткий деловой тон.

## Как это работает

```
ВКонтакте (сообщество)
      │  Long Poll (a_check, wait=25)
      ▼
 bot.py  ── handle_message() ──► ask_deepseek()
   │                                   │
   │  send_typing()                     │  POST api.deepseek.com/v1/chat/completions
   │  send_message()                    ▼
   ▼                              DeepSeek (deepseek-chat)
 conversations{peer_id: [msgs]}   ◄─ контекст до 20 сообщений
```

- `conversations` — словарь `peer_id → [сообщения]`: системный промпт + история диалога, обрезается до 20 последних.
- Главный цикл опрашивает Long Poll; на событие `message_new` вызывает `handle_message`, тот — `ask_deepseek` и `send_message`.

## Установка и запуск

### 1. Клонирование
```bash
git clone https://github.com/Ira-Korshunova/vk-deepseek-bot.git
cd vk-deepseek-bot
```

### 2. Зависимости
```bash
pip install -r requirements.txt
```

### 3. Создать сообщество ВК и получить ключи
1. На https://vk.com/groups создай сообщество.
2. **Управление** → **Работа с API** → **Создать ключ**.
3. Права: **messages** (обязательно).
4. Скопируй токен (начинается с `vk1.a.`).
5. **ID сообщества** (число) возьми из того же раздела.

### 4. Настроить `.env`
```env
DEEPSEEK_API_KEY=sk-твой_ключ_deepseek
VK_TOKEN=vk1.a.твой_токен_вк
GROUP_ID=123456789
```

### 5. Запустить
```bash
python3 bot.py
```
Бот подключится к Long Poll и начнёт принимать сообщения. **Ngrok и Callback API не нужны.**
